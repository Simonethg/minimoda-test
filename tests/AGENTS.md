# Convenciones de tests/
- Usá getByRole o getByLabel con nombres observados en la UI.
- No uses waitForTimeout ni esperas fijas.
- Incluí el ID del caso en el nombre de cada test.
- Comprobá el resultado esperado con assertions de la UI.
- Si falta un texto o locator, marcá A VERIFICAR; no lo inventes.
- No uses test.skip ni test.fixme para ocultar fallos.
- Demo permitida: https://minimoda-navy.vercel.app/checkout
