# MiniModa – Acuerdos del proyecto

- Trabajá únicamente dentro de este proyecto y con la demo de MiniModa.
- No utilices datos reales de pago ni servicios de producción.
- No guardes secretos, tokens, contraseñas ni claves en archivos, logs o commits.
- Pedí confirmación antes de instalar dependencias nuevas.
- No borres ni saltees tests para conseguir resultados exitosos.
- No utilices test.skip, test.fixme ni test.only.
- Ejecutá npx playwright test después de modificar tests.
- Si falta un dato, texto o comportamiento comprobado, marcá A VERIFICAR.
- Informá qué comandos ejecutaste y qué resultados pudiste verificar.
- Solicitá confirmación antes de operaciones destructivas.
